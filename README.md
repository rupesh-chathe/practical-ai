# AI Practical Programs (1–9)

Python programs for all nine college Artificial Intelligence practical assignments, each in a separate numbered file.

| No. | Topic | File |
| --- | --- | --- |
| 1 | Simple Reflex Vacuum Agent | `practical_01_simple_reflex_vacuum_agent.py` |
| 2 | Model-Based Grid Agent | `practical_02_model_based_grid_agent.py` |
| 3 | A* Search for 8 Puzzle | `practical_03_astar_8_puzzle.py` |
| 4 | Tower of Hanoi | `practical_04_tower_of_hanoi.py` |
| 5 | BFS Robot Path Planning | `practical_05_bfs_robot_path_planning.py` |
| 6 | N-Queens Backtracking | `practical_06_n_queens_backtracking.py` |
| 7 | Rule-Based Student Support Chatbot | `practical_07_student_support_chatbot.py` |
| 8 | Tic-Tac-Toe using Minimax | `practical_08_minimax_tic_tac_toe.py` |
| 9 | Intelligent Number-Guessing Agent | `practical_09_intelligent_number_guessing_agent.py` |

Run each practical with Python 3, for example:

```bash
python3 practical_03_astar_8_puzzle.py
```

On Windows, `python` may be used instead. Practicals 4, 7, 8 and 9 need interactive terminal input. No third-party packages are needed.

Code is based on the supplied assignment PDFs, with indentation and syntax corrected while preserving the algorithms.
